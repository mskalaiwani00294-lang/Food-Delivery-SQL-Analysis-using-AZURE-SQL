# 🍔 Food Delivery SQL Analysis Using Azure SQL

## 📌 Project Overview

This project focuses on analyzing food delivery data using SQL in Azure SQL Database. The main objective is to understand customer ordering patterns, restaurant performance, popular food items, order status, and revenue.

## 🎯 Objective

- Analyze total orders and revenue from delivered orders.
- Identify the most popular food items.
- Understand customer ordering behavior.
- Compare restaurant performance and ratings.
- Generate business insights to support better decision-making.

## 🛠️ Tools & Technologies

- **Database:** Azure SQL Database
- **Query Language:** SQL
- **Platform:** Microsoft Azure Portal

## 🗄️ Database Structure

Database Name: `food-delivery-DB`

The database contains five tables:

1. **Customers** – Stores customer details such as name, phone number, email, and city.
2. **Restaurants** – Stores restaurant names, locations, and ratings.
3. **Food_Items** – Contains food names, prices, and restaurant details.
4. **Orders** – Stores order dates, customer details, order status, and total amounts.
5. **Order_Items** – Contains food items, quantities, and item prices for each order.

## 📚 SQL Concepts Used

- CREATE TABLE
- PRIMARY KEY and FOREIGN KEY
- INSERT and SELECT
- Aggregate Functions: COUNT(), SUM(), AVG()
- JOIN Operations
- GROUP BY and ORDER BY
- TOP Clause

## 📊 Business Analysis

The following business questions were analyzed using SQL:

1. What is the total number of orders?
2. What is the total revenue from delivered orders?
3. Which food items are the most popular?
4. Which customers place the most orders?
5. Which restaurants offer the most food items?
6. What is the order count for each order status?
7. Which order has the highest total amount?
8. Which restaurants have the highest average rating?

## 🔍 My Analysis

I performed eight business analyses using SQL to understand order volume, revenue performance, popular food items, customer behavior, restaurant offerings, order status distribution, high-value orders, and restaurant ratings.

The SQL queries helped transform database records into meaningful business insights.
